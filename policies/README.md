# policies/

Dynamic offload policies and the DSL parser/runtime modules are grouped here. Sample rule files that can be consumed via `--policy dsl --policy-config <path>` live under `examples/`; see `examples/adaptive.dsl.yaml` for a queue/utilization-driven reorder/admission policy, `examples/stage_match.dsl.yaml` for a stage-aware DAG example (paired with `examples/stage_match_manifest.yaml`), `examples/stage_label_reorder.dsl.yaml` for a simple stage-label/ admission pairing used in tests (paired with `examples/stage_label_manifest.yaml`), and `examples/skew_dag_stage.dsl.yaml` for a burst-aware skew DAG rule set (paired with `examples/skew_dag_stage_manifest.yaml`). Rules can mix metric-based conditions with metadata/stage matches (`match:` blocks) so policies can target specific DAG nodes or manifest labels, and rule ordering provides fallbacks (first matching reorder + first matching admission each win their respective directive).
